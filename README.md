## 🧠 About Me

🖐️ I build systems that **see, understand, and respond** — turning hand gestures into digital commands.

Currently deep in **Real-Time Hand Tracking** using Python, MediaPipe, OpenCV & NumPy. My work sits at the intersection of **Computer Vision, AI, and Full-Stack Development**.

- 🔭 Currently building → **VisionDesk AI** — gesture-controlled desktop interface
- 🌱 Exploring → Deep Learning, Pose Estimation, LLM integration
- 🎯 Goal → Ship CV-powered products that solve real problems
- ⚡ Fun fact → I taught a computer to read my hands before I could read my own handwriting
